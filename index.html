SSAFY x 삼성전자 네트워크 사업부 | 2025.08 ~ 2025.09 (6주)

5G RAN KPI 예측 모델 개발 및 최적화

역할: 대용량 데이터 전처리 및 RAN 경량 모델 탐색

기업 보안 정책상 소스 코드 비공개

프로젝트 개요

5G RAN(무선 접속망)에서 수집되는 KPI(핵심 성능 지표)는 네트워크 서비스 운용 제어에 활용됩니다. 기존에는 현재 값을 기반으로 운용했으나, KPI를 사전에 예측하여 선제적으로 대응한다면 네트워크 혼잡 방지, 서비스 품질 향상 등의 효과를 기대할 수 있습니다. 이에 시계열 예측 모델을 활용한 KPI 예측 시스템을 개발했습니다.

주요 기능

  • 제한된 리소스(16GB RAM, 1TB 스토리지)에서 60TB 규모 데이터 전처리
  • GRU, LSTM, TCN, TFT 4가지 시계열 모델 비교 분석
  • Cell 단위 학습 전략을 통한 예측 정확도 향상
  • 4종 KPI(PRB, CQI, MCS, Throughput) 예측
  • DuckDB와 Parquet 기반 메모리 효율적 데이터 파이프라인 구축
  • ONNX Runtime 기반 경량 모델 배포

담당 역할

  • 대용량 데이터 처리
    • 압축 해제 시 60TB에 달하는 데이터를 16GB RAM 환경에서 처리
    • DuckDB와 Parquet 포맷을 활용한 메모리 효율적 전처리 파이프라인 구축
    • 시간, Cell 단위 데이터 집계 및 정제
  • 시계열 모델 비교 분석
    • GRU, LSTM, TCN, TFT 4가지 모델의 성능 비교 실험 설계 및 수행
    • Cell별 주기성 분석을 통한 최적 학습 전략 탐색
    • sin/cos 변환을 활용한 시간 파생 피처 설계
  • 경량 모델 탐색
    • 실제 RAN 장비 탑재를 고려한 ONNX 기반 모델 경량화
    • 4종 KPI에 대한 예측 정확도 및 모델 크기 트레이드오프 분석

기술 스택

AI/ML

PyTorch, GRU, LSTM, TCN, TFT, ONNX Runtime

데이터 처리

DuckDB, Parquet, Pandas, NumPy

Tools

Confluence, Notion

성과 및 배운 점

메모리 최적화 달성

  • DuckDB 도입으로 메모리 사용량 80% 감소 (80GB → 16GB)
  • Parquet 포맷 활용으로 저장 공간 86% 감소 (60TB → 8.4TB)

모델 성능 개선

  • 4종 KPI(PRB, CQI, MCS, Throughput) 모두 90% 이상 예측 정확도 달성(WAPE 기준)
  • Cell 단위 학습 전략(Site-Specific Training) 도입으로 정확도 향상 확인

기술적 인사이트

  • 제한된 리소스(16GB RAM, 1TB 스토리지)에서 대용량 데이터를 다루는 실전 경험
  • 여러 시계열 모델(GRU, LSTM, TCN, TFT)의 특성과 적용 시나리오 학습
  • Feature Engineering의 중요성 체감 (sin/cos 시간 변환 효과)

프로젝트 개요

난독증 아동에게는 반복적인 발음 훈련이 필수적이지만, 전문 교육 기관은 높은 비용 부담과 지리적 제약으로 지속하기 어렵습니다. 이에 VR과 AI 음성 인식을 결합하여 가정에서도 전문적인 발음 피드백을 받으며 몰입감 있게 한글을 학습할 수 있는 시스템을 개발했습니다. BKT 알고리즘으로 아이의 취약점을 자동 추적하고, 모바일 앱으로 학습 진도를 관리합니다.

주요 기능

  • 실시간 AI 음성 피드백 (발음 오류 자동 탐지 및 취약점 반복 훈련 제공)
  • 4단계 체계적 훈련 시스템 (자음/모음 → 음절 분리 → 음소 인지 → 한 글자 합성)

  • 부모/교사용 대시보드 (취약점 분석 레포트, 숙련도 추이 그래프)
  • 몰입형 3D VR 환경 (곡면 UI 패널, 마법학교 스토리텔링)

담당 역할

  • AI 음성 인식 모델 개발
    • Wav2Vec2 사전학습 모델 기반 한국어 어린이 음성 Fine-tuning (43.6만 시간 사전학습)

    • FastAPI 기반 실시간 음성 인식 추론 서버 구축 (평균 30ms 응답)
    • 음소 유사도 분석 및 피드백 API 개발
